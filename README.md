# 🛡️ Phishing URL Detector

A Machine Learning powered web app to detect fake and phishing URLs to keep users safe online.

## 🚀 Features
* Machine Learning model trained to identify malicious links.
* Built using Python, Flask, HTML, and Scikit-Learn.
* Fast and lightweight Web Interface.

## 🛠️ How to Run Locally

1. Clone or Download this repository.
2. Open Command Prompt in the project folder.
3. Install required libraries:
   ```bash
   pip install -r Requirements.txt
